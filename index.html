Sobre / Aviso técnicox
Este painel faz chamadas diretamente do seu navegador para: https://api.portaldatransparencia.gov.br/api-de-dados/despesas/por-orgao Isso é um app puramente client-side (HTML/JS), sem servidor por trás. Duas coisas podem impedir a consulta real: 1) CORS — a API do Portal da Transparência foi feita para ser chamada por programas (Python, backend, etc.), não necessariamente por navegadores rodando em outro domínio. Se o servidor não devolver o cabeçalho Access-Control-Allow-Origin liberando este site, o navegador vai BLOQUEAR a resposta antes mesmo de ela chegar aqui — e isso não tem solução do lado do JavaScript, só rodando o pedido a partir de um servidor/proxy seu. 2) Limite de requisições — o Portal limita o número de chamadas por minuto por chave. Se a consulta falhar, o painel mostra o erro exato e oferece "Carregar dados de exemplo" para você testar gráficos, tabela e exportação com dados fictícios no mesmo formato. Isso não é uma falha de implementação — é assim que a maioria das APIs de governo se comporta quando chamadas direto do navegador. Para uso jornalístico real, rode esta mesma lógica de fetch em um script Python/Node (o botão "Citação" já te dá a URL exata usada).
